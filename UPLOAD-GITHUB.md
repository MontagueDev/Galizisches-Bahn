# Actualización del repositorio desde iPhone

1. Descomprime el ZIP.
2. En el repositorio abre `Add file` → `Upload files`.
3. Sube todos los archivos de la raíz y confirma el commit en `main`.
4. Entra en `icons` y reemplaza todos los PNG.
5. Espera a que GitHub Pages termine en `Actions`.
6. Abre el sitio en una pestaña privada para comprobar la nueva caché v0.6.0.
