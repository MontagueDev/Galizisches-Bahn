# Galizische Bahn v0.7.0

PWA ferroviaria ficticia para la Bundesrepublik Galizien.

## Novedades principales

- Navegación reorganizada en cinco áreas: Start, Reisen, Stadt, Tickets y Mehr.
- Viajes a México exclusivamente mediante San Juan del Río Grenzbahnhof.
- Transbordo obligatorio entre ICE/IC/RE y RB México.
- Control migratorio y aduanero de 45 minutos en San Juan del Río.
- Advertencia obligatoria del Auswärtiges Amt antes de buscar conexiones con México.
- Centro fronterizo y estado operativo propio.
- Mapas esquemáticos U-Bahn/S-Bahn para todas las áreas metropolitanas incluidas.
- Mapa nacional actualizado con la línea RB San Juan del Río–Ciudad de México Buenavista.
- Ocupación y composición simulada de trenes.

## Importante

Los horarios, rutas, posiciones y pagos son simulados. No se deben introducir datos bancarios reales.
