# Pruebas recomendadas

1. Buscar Guadalajara Hbf → Löwenstadt Hbf y completar el pago con `4242 4242 4242 4242`.
2. Buscar Guadalajara Hbf → Ciudad de México Buenavista y verificar aviso Bundespolizei.
3. Cambiar la hora a 22:00 para mostrar NightJet cuando exista ruta compatible.
4. Abrir `In der Stadt`, cambiar de ciudad, alternar U-Bahn/S-Bahn y planear una ruta.
5. Comprar un boleto urbano.
6. Suscribirse al Galizien-Ticket Standard.
7. Revisar boletos, suscripciones, perfil e historial de compras.
8. Probar el pago rechazado con `4000 0000 0000 0002`.
